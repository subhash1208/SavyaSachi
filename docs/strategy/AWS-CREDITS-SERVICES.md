## Cost Optimization Strategies

### 1. Minimize Amazon Connect Usage
- **Strategy**: Test with minimal calls, use recorded demos
- **Savings**: Each avoided minute saves $0.038
- **Action**: Record 3-4 perfect demo calls, replay videos instead of live calls

### 2. Optimize Bedrock Usage
- **Strategy**: Use smaller context, cache responses, test with Haiku first
- **Savings**: Claude Haiku is 20x cheaper than Sonnet
- **Action**: Develop with Haiku ($0.25/$1.25 per 1M tokens), switch to Sonnet only for final demo

### 3. Replace QuickSight with CloudWatch
- **Strategy**: Use CloudWatch Dashboards (free tier) instead of QuickSight
- **Savings**: $9/month
- **Action**: Build disease surveillance dashboard in CloudWatch

### 4. Batch SMS Testing
- **Strategy**: Test SMS flow with console logs first, send actual SMS only when confirmed working
- **Savings**: $0.00645 per avoided SMS
- **Action**: Use mock SMS for 90% of testing

### 5. Use Transcribe Free Tier Wisely
- **Strategy**: Stay within 60 min/month free tier
- **Savings**: $0.024/min for overages
- **Action**: Test regional languages sparingly, focus on Hindi (Nova Sonic)

### 6. Set Up Billing Alarms
- **Action**: Create CloudWatch billing alarm at $100, $150, $180
- **Benefit**: Get notified before credits run out
